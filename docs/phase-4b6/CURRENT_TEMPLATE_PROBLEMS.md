# Current Template Problems

## Baseline

Phase 4B.5 proved that Direction A assets could be rendered, but its
`EditorialPaperCollageV1` candidate was still a collection of five unrelated
3:4 layouts rather than a reusable short-video system.

## Confirmed problems

- Canvas was 720×960 (3:4), which compressed hero artwork and encouraged
  column-based composition.
- Five layout identities (`split-column`, `scale-contrast`,
  `staggered-notes`, `full-bleed-turn`, `quiet-asymmetry`) changed the reading
  rule from segment to segment.
- Caption copy was integrated into each layout, so its position and hierarchy
  moved between scenes.
- English labels, sequence numbers, a blue vertical rail, an orange turning
  block and repeated rules existed as template decoration rather than content.
- Every scene had a different framing grammar; continuous viewing did not feel
  like one editorial system.
- The three-action scene presented all items as a static arrangement instead
  of establishing them in narration order.
- Camera motion was stable but visually repetitive, and the turning/end cards
  reduced the depth already present in the artwork.

## Correction boundary

Phase 4B.6 corrects canvas, scene grammar, caption placement, motion and
transition vocabulary only. It does not add real-book content, word-level
captions, waveform/HUD elements, audio finalization, batch production, a web
surface, or a default renderer.
