# Phase 4C Prerequisites

Phase 4C may be a single controlled real-book validation only if all of the following are met:

- One explicitly selected book and one bounded output; no batching.
- Rights evidence for every real cover, excerpt, image, font and audio asset is recorded before use.
- Public release remains disabled unless H2 is independently cleared.
- The same Renderer Contract, Request hash, Attempt staging, Final Mix and external QC boundaries remain active.
- `PaperCollageVisualV1` remains opt-in and the default renderer is not changed.
- No Provider, Web, Audio Finalizer, word highlighting, waveform or overlay-system expansion is bundled into the validation.
- Static-frame and full-video human review checks typography, cropping, pacing and editorial suitability.
- Current dependency and Remotion-license gates remain documented.

Conclusion: technically allowed to enter one controlled real-book validation, but not allowed to publish or batch-produce by default.
