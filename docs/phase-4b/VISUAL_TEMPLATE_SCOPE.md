# Visual Template Scope

## Included

- Composition: `PaperCollageVisualV1`.
- Template: `paper-collage-visual-v1@0.1.0-experimental`.
- Attempt-staged SVG paper texture and JSON theme tokens.
- Paper background, backing sheet, still-image card, segment marker and caption card.
- Deterministic frame-driven subtle motion.
- Six-frame `paper-cut` displacement transition.
- Explicit 1.2-second fixture opening card.
- Sentence-level captions with a two-line maximum.
- Preview, final experimental render, five frozen stills and external technical QC.

## Excluded

- Production cutover, batch production and Web integration.
- Provider calls, remote media and commercial assets.
- Audio mixing, word highlighting, waveform, HUD, stickers, Lottie, GSAP and 3D.
- Real book titles, excerpts, covers, people or channel branding.

This is a controlled visual-template experiment, not a production-readiness claim.
