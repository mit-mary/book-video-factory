# Source Artwork Provenance

Mode: built-in image-generation tool. No CLI fallback and no external stock source were used. The three atlases are project-bound, text-free source artwork; all Chinese copy is applied later by `generate_direction_frames.py`.

## Direction A final prompt

Use case: stylized-concept. Source artwork atlas for five vertical editorial paper-collage keyframes. Create one cohesive, text-free editorial collage artwork containing five clearly separated visual vignettes for a mature short-form video about small choices changing a life: an adult hand tearing dark paper to reveal amber light; a tiny brass toggle switch and oversized shadow; clock, stop hand and folded paper heart; a sharply bending paper road; and a small silhouette walking toward light. Use sophisticated adult editorial illustration, photorealistic fragments, gouache, charcoal, torn-paper edges, asymmetrical compositions, warm ivory/charcoal/rust/cobalt/amber and useful negative space. No text, letters, numbers, logos, watermark, book cover, recognizable face, childlike scrapbook or generic geometric placeholders.

## Direction B final prompt

Use case: stylized-concept. Source artwork atlas for five vertical Quiet Book Notes keyframes. Create five separated mature reading-and-thinking vignettes: an open page with graphite underline and torn window of amber light; a tiny pencil mark and mustard tab in large blank space; clock sketch, margin bracket and folded note with fingerprint; page-edge tabs turning around a corner with a curved pencil arrow; and a nearly blank spread with a bookmark in morning light. Use realistic uncoated paper, pencil, vellum, linen thread, quiet literary still life, bone/graphite/mustard/burgundy/sage and varied close-up/overhead compositions. No text, readable handwriting, logos, watermark, commercial cover, recognizable face, sticker clutter or generic geometry.

## Direction C final prompt

Use case: stylized-concept. Source artwork atlas for five vertical Visual Metaphor Collage keyframes. Create five separated adult visual metaphors: a tiny brass lever moving a massive dark paper plane; a miniature red switch moving a massive shadow; sparse clock/moon, gate/hand and cracked shell/light symbols; a rail that runs straight then bends; and a compass aligned toward a distant warm opening. Use sophisticated conceptual editorial collage, heavy cotton paper, charcoal, brass, muted vermilion, amber light, radical composition changes and generous typography space. No text, letters, numbers, logos, watermark, cover, recognizable face, cute stickers, generic geometry or literal sentence illustration.
