# User Selection Gate

## Status

`WAITING_FOR_VISUAL_DIRECTION_APPROVAL`

Stage 1 is complete. Stage 3 template implementation is blocked until the user explicitly selects one of:

- `A` — Editorial Paper Collage
- `B` — Quiet Book Notes
- `C` — Visual Metaphor Collage
- a clearly described mixed direction, such as `C + A typography`

## What selection authorizes

Selection authorizes implementation of one chosen direction only, with four to six scene layouts and frozen-fixture Preview/Final validation.

Selection does not authorize real-book use, public release, batch production, Provider integration, Web work, Audio Finalizer, default-renderer replacement, word highlighting, waveform or HUD.

No Remotion template code has been changed in Stage 1.
